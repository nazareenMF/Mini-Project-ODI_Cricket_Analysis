# ODI Cricket Analysis

## Project Overview
This project analyzes One Day International (ODI) cricket data using Microsoft Excel and Power BI to transform match records into clear performance metrics, player insights, and team trends.

## Tools Used
- Microsoft Excel
- Power BI
- Power Query
- DAX (Data Analysis Expressions)

## Data Cleaning & Transformation
- Removed duplicate match and player records
- Handled missing statistical values and incomplete scorecards
- Standardized date, venue, and team naming formats
- Created calculated columns and measures using DAX for key cricket statistics

## Dashboard Features
The interactive Power BI dashboard provides:
- KPI cards for top-level match and performance summaries
- Interactive slicers to filter by team, player, venue, and year
- Charts and graphs visualizing batting and bowling trends
- Drill-through analysis for deep-diving into individual player metrics

## Key Insights
- Target Chasing vs. Setting Scores: Analysis of win rates based on batting first versus fielding first.
- Impact of the Toss: Correlation between winning the toss and ultimate match victory across different venues.
- Player Performance Profiles: Top run-scorers and wicket-takers evaluated by consistency and impact metrics.
