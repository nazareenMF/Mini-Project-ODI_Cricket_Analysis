# ODI Cricket Data Analysis

## Project Overview

This project is an end-to-end data analytics project based on One Day International (ODI) cricket data.

The project focuses on cleaning, transforming, analyzing, and visualizing cricket data to identify meaningful insights related to teams, players, batting, bowling, matches, and venues.

The analysis was performed using Microsoft Excel and Microsoft Power BI.

---

## Project Objectives

The main objectives of this project are:

- Clean and preprocess raw ODI cricket datasets.
- Handle missing, duplicate, and inconsistent data.
- Transform the datasets into a structured format suitable for analysis.
- Analyze team and player performance.
- Identify top batsmen and bowlers.
- Analyze batting and bowling statistics.
- Calculate team win percentages and other performance indicators.
- Analyze venues and host countries.
- Develop an interactive Power BI dashboard.
- Generate meaningful insights and recommendations from the analysis.

## Data Cleaning and Preprocessing

The following preprocessing steps were carried out:

- Removed duplicate records.
- Identified and handled missing values.
- Standardized data formats.
- Corrected inconsistent values.
- Converted columns to appropriate data types.
- Handled null and blank values.
- Created calculated fields where required.
- Checked relationships between datasets.
- Prepared the cleaned datasets for Power BI analysis.
